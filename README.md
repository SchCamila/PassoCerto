# Passo Certo

Aplicativo que ajuda trabalhadores brasileiros por conta própria a decidir se
vale a pena se formalizar como MEI, a dar esse passo e a manter o registro em dia.

> Projeto acadêmico de Engenharia de Software voltado à ODS 8 da ONU
> (trabalho decente e crescimento econômico — metas 8.3, 8.5, 8.8 e 8.10).

Este README será completado ao final da implementação (seção "Módulos",
parâmetros legais, fontes e limitações). Por ora, veja `DEPLOY.md` (em breve)
para publicar o projeto.
